# 🎓 TutorFlow Premium
> **An AI & Data Science Powered EdTech Management Platform**

TutorFlow Premium is a high-performance full-stack web application designed to connect local students with verified academic instructors. Built with a pythonic micro-architecture, it automates coaching administration including attendance tracking, dynamic fee management, and secure account verification loops.

---

## ✨ Core Features

* **Dual-Portal Logic:** Dedicated, isolated workspaces for Instructor Dashboards and Student Console.
* **Live Email Authentication:** Secure asynchronous email verification system using Flask-Mail SMTP and Google App Passwords.
* **Glassmorphic UI Engine:** Premium interactive interface with high-performance light/dark mode synchronization.
* **Coaching Operations Hub:** Modular grids for locking daily student attendance and generating instant monthly fee invoices.
* **Cascade Purge Architecture:** Structural relational integrity that ensures all linked data is wiped safely during account deletion.

---

## 💻 Tech Stack Specification

* **Backend Engine:** Python 3.10+ / Flask Enterprise Architecture
* **Database Platform:** PostgreSQL (Render Cloud Managed Cluster) / Flask-SQLAlchemy ORM
* **Mail Protocol:** SMTP Network Transfer (Port 587) with TLS Security
* **UI Interface Engine:** HTML5, CSS3 Glassmorphism, Bootstrap 5.3, Native JavaScript ES6
* **Production Deployment:** WSGI Gunicorn Application Server Stack
